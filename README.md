# 星炬长明：江苏高校科学家精神戏剧剧场

红金舞台风的静态网站 Demo，用于展示江苏高校科学家精神校园原创戏剧。

## 本地预览

直接打开 `index.html`，或在目录中运行：

```bash
python3 -m http.server 8000
```

浏览器访问 <http://localhost:8000>。

## 功能

- 三张自动轮播主题海报
- 按高校展示剧目资料
- 新闻动态版块
- 基于浏览器 `localStorage` 的 Demo 留言墙
- 桌面、平板和手机响应式布局

> 当前剧目、新闻与链接为版式示例，正式上线前请替换成经过核实的真实内容。
